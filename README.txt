PORTAIL DYNAMIQUE CAT ÉNERGIES CATTENOM

Fichiers à déposer ensemble dans le même dossier GitHub :
- index.html
- communications.json

Pour ajouter une communication :
1. Ouvrir communications.json
2. Ajouter un nouvel objet JSON dans la liste
3. Enregistrer / Commit sur GitHub
4. Le portail affichera automatiquement la nouvelle communication au prochain chargement

IMPORTANT :
Ne pas ouvrir index.html uniquement en double-cliquant dessus sur Windows pour tester le chargement JSON.
Le navigateur peut bloquer fetch() en mode fichier local.
Tester plutôt une fois les deux fichiers publiés via GitHub Pages.

Le logo CAT Énergies est intégré directement dans index.html : aucun fichier image séparé n'est nécessaire.
